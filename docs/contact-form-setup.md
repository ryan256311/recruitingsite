# お問い合わせフォームの構成

お問い合わせは **Google フォーム**で受け付けます。サイト内にフォームは持ちません。

```
採用サイトのCTA（9箇所）
   │ 外部リンク（別タブ）
   ▼
Google フォーム「株式会社エクシート 採用お問い合わせ」
   ├─ 回答 ──▶ スプレッドシート「採用サイト お問い合わせ」
   ├─ 新着通知 ──▶ 採用担当へメール
   └─ 回答のコピー ──▶ 応募者へ自動返信
```

サイト側はリンクを置くだけなので、**APIキーも合言葉も存在しません**。

## 添付ファイルを扱わない理由

Googleフォームでファイル添付の設問を使うと、**回答者にGoogleアカウントでのログインが必須**になります。採用フォームでは応募の離脱につながるため、添付は設けていません。

**履歴書・職務経歴書は、受付後に担当者からのメールへ返信する形で送っていただく運用**です。フォームの説明文と送信完了画面にその旨を記載しています。

## 運用

### 応募を確認する

スプレッドシートを開くと、1行が1件の応募です。
進捗を管理したい場合は、右端に「対応状況」などの列を自由に追加してください（フォームの回答列は自動で追加されるため、**左側ではなく右端に**足すのが安全です）。

### 新着に気づく

フォームの編集画面 → **回答**タブ → 右上のメニュー → **新しい回答についてメール通知を受け取る** をオンにします。

さらに確実にしたい場合は、スプレッドシートの **ツール → 通知設定** でも設定できます。

### 設問を変える

フォームの編集画面から直接変更できます。コードの修正は不要です。

ただし **選択肢（お問い合わせ種別・採用区分）の文言を変えると、CTAの事前選択が効かなくなります**。変更する場合は `src/app/data/forms.ts` の値も合わせて修正してください。

### フォームを作り直した場合

URLと設問IDが変わるため、`src/app/data/forms.ts` の `FORM_BASE` と `ENTRY` を更新する必要があります。
`scripts/apps-script/create-form.gs` の `getPrefilledUrls()` を実行すると、新しいURLが出力されます。

---

## スパム対策

Googleフォームには reCAPTCHA による保護が入っています。サイト側で追加の対策は不要です。

迷惑な回答が続く場合は、フォームの設定で「回答を受け付ける」をオフにするか、ログイン必須に切り替えることで即座に止められます。
