# お問い合わせフォームの設置手順

応募データは **Google スプレッドシートの1行が記録の正本**です。
メール通知は補助であり、送信に失敗しても応募データは残ります。

```
ブラウザ（/contact）
  ├─ 添付ファイル ──→ /api/upload ──→ Cloudflare R2（非公開バケット）
  └─ 送信ボタン ────→ /api/contact ──→ Apps Script
                                        ├─ スプレッドシートに1行追記  ← 記録
                                        ├─ 採用担当へ通知メール
                                        └─ 応募者へ自動返信メール
```

メール送信サービス（Resend 等）は使いません。Google アカウントから送信します。

---

## 作業A：スプレッドシートと Apps Script

### A-1. スプレッドシートを作る

1. Google ドライブで新しいスプレッドシートを作成
2. 名前を「採用サイト お問い合わせ」などに変更

シートの見出し行はスクリプトが自動で作るので、手で用意する必要はありません。

### A-2. スクリプトを貼り付ける

1. スプレッドシートのメニューから **拡張機能 → Apps Script**
2. 既定で開いている `コード.gs` の中身を**すべて削除**
3. このリポジトリの `scripts/apps-script/Code.gs` の中身を**すべて貼り付け**
4. 保存（Ctrl+S）

### A-3. 設定値を登録する

スクリプトは合言葉と通知先をコード外から読みます。コードに直接書かないでください。

1. 左メニューの **⚙️ プロジェクトの設定**
2. 一番下の **スクリプト プロパティ** → **スクリプト プロパティを追加**
3. 次の2つを登録して保存

| プロパティ | 値 |
|---|---|
| `WEBHOOK_SECRET` | 下の「合言葉の作り方」で生成した値 |
| `ADMIN_EMAIL` | 応募通知を受け取るメールアドレス |
| `SHEET_ID` | 記録先スプレッドシートのID（URLの `/d/` と `/edit` の間の文字列） |

> `SHEET_ID` は、スプレッドシートの「拡張機能 → Apps Script」から作った場合は省略できます。
> Apps Script を単独で作った場合は必須です。

> `WEBHOOK_SECRET` はサイト側と共有する合言葉です。これが一致しないリクエストは拒否されます。

#### 合言葉の作り方

**このリポジトリは公開されています。合言葉の実値をファイルに書かないでください。**
手元で次を実行し、出てきた値をスクリプトプロパティと Vercel にだけ貼り付けます。

```bash
node -e "console.log(require('crypto').randomBytes(24).toString('base64url'))"
```

### A-4.（任意）送信元アドレスを会社のものにする

何もしないと、メールの送信元はこのスクリプトを置いた **Google アカウントのアドレス**（@gmail.com）になります。
応募者への自動返信を `recruit@exceet.co.jp` から送りたい場合は、次の手順で変更できます。

1. Gmail を開く → **設定 → アカウントとインポート → 他のメールアドレスを追加**
2. `recruit@exceet.co.jp` を追加し、届いた確認コードを入力して認証
3. Apps Script のスクリプトプロパティに `FROM_ALIAS` = `recruit@exceet.co.jp` を追加

認証していないアドレスを指定しても無視され、通常のアドレスで送信されます（エラーにはなりません）。

### A-5. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 歯車アイコン → **ウェブアプリ** を選択
3. 設定：
   - **説明**: `採用サイト お問い合わせ受付`
   - **次のユーザーとして実行**: **自分**
   - **アクセスできるユーザー**: **全員**
4. **デプロイ** をクリック
5. 初回は権限の確認が出ます。**アクセスを承認** → アカウントを選択 → 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** → **許可**
6. 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー

> 「アクセスできるユーザー: 全員」にしないと、サイトから呼び出せません。
> URL を知られても、合言葉が合わなければ記録もメール送信も行われません。

### A-6. 動作確認

コピーした URL をブラウザで開いてください。次のように表示されれば設置成功です。

```json
{"ok":true,"message":"採用サイトのお問い合わせ受付が動作しています"}
```

**この URL を私（開発側）にお知らせください。** Vercel の環境変数に登録します。

> ⚠️ コードを修正したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ** で更新してください。
> 「新しいデプロイ」を選ぶと URL が変わってしまいます。

## 作業B：Cloudflare R2（添付ファイルの保管）

履歴書・職務経歴書を保管します。**バケットは非公開のまま**にしてください。
ファイルはサイト経由（`/api/files`）でのみ取得でき、都度期限付きのURLが発行されます。

### B-1. バケットを作る

1. [Cloudflare](https://dash.cloudflare.com/) にログイン（無料プランで可）
2. 左メニュー **R2** → **Create bucket**
3. バケット名: `recruit-files`
4. Location: `Asia-Pacific` を推奨
5. **作成後、パブリックアクセスは有効にしないでください**

### B-2. APIトークンを作る

1. R2 の画面右上 **Manage R2 API Tokens** → **Create API token**
2. 権限: **Object Read & Write**
3. 対象バケット: `recruit-files` のみ
4. 作成後に表示される次の3つを控える（**再表示できません**）
   - Access Key ID
   - Secret Access Key
   - エンドポイント（`https://<アカウントID>.r2.cloudflarestorage.com`）

**この3つを私にお知らせください。**

## 作業C：Vercel の環境変数

作業A・Bで得た値を登録します。私が代行することもできますが、ご自身で行う場合は以下の通りです。

[Vercel の環境変数ページ](https://vercel.com/ryohei-shinkes-projects/recruitingsite.next/settings/environment-variables) で
**Add Environment Variable** から1つずつ追加し、Environments は **All Environments** を選びます。

| 変数名 | 値 |
|---|---|
| `GAS_WEBHOOK_URL` | 作業A-6でコピーしたURL |
| `GAS_WEBHOOK_SECRET` | Apps Script の `WEBHOOK_SECRET` と同じ値 |
| `FILE_ACCESS_SECRET` | 下の「合言葉の作り方」で生成した値 |
| `R2_ENDPOINT` | 作業B-2のエンドポイント |
| `R2_ACCESS_KEY_ID` | 作業B-2のAccess Key ID |
| `R2_SECRET_ACCESS_KEY` | 作業B-2のSecret Access Key |
| `R2_BUCKET_NAME` | `recruit-files` |

登録後、**再デプロイが必要です**（環境変数はビルド時に取り込まれるため）。

## 運用

### 応募を確認する

スプレッドシートを開くと、1行が1件の応募です。
**対応状況**の列は担当者が自由に書き換えてください（未対応 / 対応中 / 完了 など）。

添付ファイルはファイル名のリンクをクリックすると開きます。

### 新しい応募に気づく

通知メールが `ADMIN_EMAIL` 宛に届きます。
さらに確実にしたい場合は、スプレッドシートの
**ツール → 通知設定 → 編集内容の通知ルール** で「変更があったとき」「すぐに通知」を設定してください。

### メール送信の上限

| アカウント種別 | 1日あたりの送信先数 |
|---|---|
| 個人の Gmail | 100 |
| Google Workspace | 1,500 |

1件の応募で2通（担当者＋応募者）送るため、個人Gmailでは1日50件が上限の目安です。
採用サイトの流量であれば十分ですが、超えるとその日の送信が止まります（**記録は残ります**）。

### 添付ファイルの上限

**1ファイルあたり4MBまで**です。
Vercel がリクエストボディを4.5MBに制限しているため、これ以上は受け取れません。
