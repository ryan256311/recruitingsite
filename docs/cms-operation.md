# 採用サイト コンテンツ更新マニュアル

採用サイトの「お知らせ」「コンテンツ記事」「求人情報」は、microCMSの管理画面から更新できます。コードを触る必要はありません。

---

## 1. ログイン

1. https://app.microcms.io を開く
2. 登録したメールアドレスとパスワードでログイン
3. 「採用サイト - エクシート」を選ぶ

直接開く場合は https://exceet-recruit.microcms.io です。

左側に **お知らせ / コンテンツ / 求人** の3つが並んでいます。これがそれぞれの保管場所です。

---

## 2. お知らせを1件追加する

一番よく使う操作です。

1. 左メニューから **お知らせ** を選ぶ
2. 右上の **「追加」** を押す
3. 次の項目を入力する

| 項目 | 入力内容 |
|---|---|
| 日付 | サイトに表示したい日付 |
| タイトル | お知らせの見出し |
| カテゴリ | 新卒 / ニュース / その他 から選ぶ |
| 本文 | お知らせの中身。見出しや太字はツールバーから付けられる |
| アイキャッチ画像 | 任意。入れなくてもよい |
| 外部リンクURL | 任意。下の説明を読んでください |

4. 右上の **「下書き保存」** を押す
5. **「画面プレビュー」** を押して、本番と同じ見た目を確認する
6. 問題なければ **「公開」** を押す

公開するとサイトに数秒〜1分ほどで反映されます。

### 外部サイトへのリンクだけを載せたいとき

「○○のページに詳細があります」のように、**外部サイトへ飛ばすだけのお知らせ**も作れます。

- **外部リンクURL** にそのページのURLを入れる
- **本文は空のままでよい**

こうすると、サイトの一覧でそのお知らせをクリックした人は、詳細ページを経由せず直接その外部サイトへ移動します。

---

## 3. コンテンツ記事を追加・編集する

インタビューや社内紹介などの記事です。

1. 左メニューから **コンテンツ** を選ぶ
2. **「追加」**（または既存の記事をクリックして編集）
3. 次の項目を入力する

| 項目 | 入力内容 |
|---|---|
| タイトル | 記事の見出し |
| 概要 | 一覧に出る短い説明文。2〜3行程度 |
| 本文 | 記事の中身 |
| アイキャッチ画像 | 一覧のサムネイルになる。**未設定でもOK**（下の説明を読んでください） |
| カテゴリ | 会社を知る / 仕事を知る / 仲間を知る / 働く環境 / 対話を知る |
| タグ | 複数選択できる |
| 掲載日 | 記事に表示する日付 |

4. 下書き保存 → 画面プレビュー → 公開

### アイキャッチ画像を設定しなかった場合

その記事のサムネイルは、エクシートのロゴが入った**青いプレースホルダー画像**になります。記事が一覧から消えることはないので、写真が用意できていない記事もそのまま公開して構いません。

あとから画像を設定すれば、数分でサイト側も差し替わります。

### 本文に画像を入れる

本文の入力欄のツールバーから画像ボタンを選び、パソコンの画像をアップロードします。一度アップロードした画像は「メディア」に保存され、他の記事でも使い回せます。

---

## 4. 求人情報を追加・編集する

1. 左メニューから **求人** を選ぶ
2. **「追加」**（または既存の求人をクリックして編集）
3. 項目が多いので、埋められるところから入力する

必須の項目は次のとおりです。

| 項目 | 入力内容 |
|---|---|
| URL識別子 | 下の注意を読んでください |
| 募集区分 | キャリア採用 / 新卒採用 |
| 職種名・部署名・部署紹介 | |
| 職種区分 | エンジニア / 営業 / 製造 / 事務 など |
| 概要・募集背景 | |
| 応募要件・業務内容 | **1行に1項目**ずつ入力する（下の説明を読んでください） |
| 給与・勤務地・雇用形態 | |

歓迎スキル、開発環境、福利厚生などは任意です。入力しなければサイトにその欄は出ません。

### 箇条書きになる項目は「1行に1つ」

応募要件、業務内容、歓迎スキル、アピールポイント、待遇・福利厚生、選考プロセス、開発環境の各項目は、**改行で区切って1行に1つずつ**書いてください。サイト上では自動的に箇条書きになります。

```
フロントエンドエンジニアとしての実務経験（1年以上）
WordPressを用いたコーディング実務経験
普通自動車第一種免許
```

↑ これで3項目の箇条書きになります。空行は無視されるので、間が空いても問題ありません。

項目名の末尾に「（1行に1つ）」と書いてあるものがこの形式です。

### URL識別子は既存の求人で変更しないでください

この値がそのまま求人ページのURLになります（`1` なら `/career/1`）。既存の求人で変更すると、**求人サイトや名刺に載せた既存のリンクが切れます。**

新しい求人を追加するときは、既存とかぶらない番号（`8`、`9`…）を入れてください。

---

## 5. 公開日時を予約する

「4月1日に公開したい」という場合に使います。

1. 記事を下書き保存する
2. **「公開」ボタンの横の矢印** を押し、**「公開予約」** を選ぶ
3. 公開したい日時を指定して確定する

### 時刻厳守の告知は手動公開をおすすめします

予約公開が実行される時刻は、**数分前後する可能性があります**（microCMS側の仕様で、正確な時刻は保証されていません）。

「9時ちょうどに公開」のように時刻が重要な告知は、予約ではなく、その時間に手動で「公開」を押してください。

---

## 6. 間違えたときに戻す

記事の編集画面の **「履歴」** から、過去の内容を確認できます。

- 内容の確認と比較はいつでもできます
- **過去の状態に戻す操作は、現在のプラン（Hobby）ではできません**。履歴の内容を見ながら手で直してください

公開を取り消したいときは **「非公開にする」** を押します。サイトからは消え、下書きとして残ります。

---

## 7. 公開したのにサイトに出ないとき

次の順に確認してください。

1. **本当に「公開」になっているか** — 下書き保存だけではサイトに出ません。記事の状態が「公開中」になっているか確認
2. **10分待つ** — 通常は数秒で反映されますが、まれに最大10分かかります
3. それでも出ない場合は、担当エンジニアに連絡してください

---

## 8. やらないでほしいこと

| 操作 | 理由 |
|---|---|
| カテゴリの選択肢を増やす・名前を変える | サイト側のコードが選択肢と対応しているため、追加しても表示されず、変更すると記事が一覧から消えます。増やしたいときは担当エンジニアに相談してください |
| 既存求人の「URL識別子」を変える | 既存のリンクが切れます |
| APIの設定（スキーマ）を変える | サイトが表示されなくなる可能性があります |
| APIキーを外部に共有する | サイトのコンテンツを誰でも書き換えられる状態になります |

### キャリア採用ページに出る求人について

求人を追加すると、**募集中の求人一覧（/jobs）と求人の詳細ページには自動的に出ます**。

ただし**キャリア採用ページ（/career）に載せる求人は、コード側で指定しています**。ここに新しい求人を載せたいときは担当エンジニアに連絡してください。管理画面の操作だけでは変わりません。

---

## 9. 困ったときの連絡先

担当エンジニア: （記入してください）

連絡するときは、次を伝えてもらえると調査が速くなります。

- どのコンテンツか（お知らせ / コンテンツ / 求人、記事のタイトル）
- 何をしたか（公開した、編集した、予約した）
- 画面に出たエラーメッセージ（あれば）

## キャリア採用ページに載せる求人を変える

`/career` には、すべての求人ではなく選んだものだけを掲載しています。

1. microCMS の **求人** から、対象の求人を開く
2. 一番下の **「キャリア採用ページに表示する」** のスイッチを切り替える
3. **公開** を押す

数十秒でサイトに反映されます。コードの修正もデプロイも不要です。

オフにした求人も、**募集中の求人一覧（/jobs）と求人の詳細ページには引き続き表示されます**。
`/career` のトップに並べるかどうかだけが変わります。
